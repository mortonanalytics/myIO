# Equal Units per Pixel on x and y

Makes one unit on the x axis as long on screen as one unit on the y
axis, for maps, plans and images where x and y are the same kind of
distance. The tighter axis is widened about its center; any limits from
[`setAxisLimits`](https://mortonanalytics.github.io/myIO/reference/setAxisLimits.md)
still set where the view starts.

## Usage

``` r
setEqualAspect(myIO, enabled = TRUE)
```

## Arguments

- myIO:

  A myIO widget.

- enabled:

  `TRUE` (default) to turn equal aspect on, `FALSE` to turn it off.

## Value

A modified `myIO` widget.

## Examples

``` r
grid <- expand.grid(x = seq(0, 10, by = 0.5), y = seq(0, 4, by = 0.5))
grid$v <- grid$x * grid$y
myIO() |>
  addIoLayer(type = "raster", label = "v", data = grid,
             mapping = list(x_var = "x", y_var = "y", value = "v")) |>
  setEqualAspect()
```
