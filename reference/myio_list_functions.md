# List myIO Functions for LLM Tool Calling

List myIO Functions for LLM Tool Calling

## Usage

``` r
myio_list_functions()
```

## Value

A character vector of exported myIO function names.

## Examples

``` r
head(myio_list_functions())
#> [1] "addIoLayer"              "clear_duckdb_wasm_cache"
#> [3] "defineCategoricalAxis"   "dragPoints"             
#> [5] "duckdb_wasm_status"      "flipAxis"               
```
