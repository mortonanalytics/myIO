# Contributing to myIO

Thanks for your interest. Open an issue first for anything non-trivial,
so we can tell you quickly whether the change fits before you spend time
on it.

## License

By contributing, you agree that your contribution is licensed under the
project’s license (MIT), the same terms everyone else receives. No
separate agreement is needed.

## Conduct and security

Everyone in project spaces follows the [Code of
Conduct](https://mortonanalytics.github.io/myIO/CODE_OF_CONDUCT.md).
Report vulnerabilities privately as described in
[SECURITY.md](https://mortonanalytics.github.io/myIO/SECURITY.md), not
in a public issue.
